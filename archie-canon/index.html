Delta memory reference

numerical semantics matter
u = write_rate · key
G = key · uᵀ
S = I + triu(G,1)
T = solve_triangular(S,I)
r = state · uᵀ − writeᵀ
y = (state · qᵀ − r · T · coupling)ᵀ
state' = state − r · T · key

The serial recurrence is mathematically equivalent on well-conditioned random FP32, but the trained checkpoint occupies a numerically sensitive geometry where operation ordering matters.

Semantics split discovered

important

Reference-repeat: exactly deterministic in the tested court: logit L∞ 0, loss Δ 0, gradient max 0.

Reference vs Triton: logit L∞ 0.015625; loss Δ ~7.9e−5; gradient rel-L2 ~0.00215.

Translation: the kernel is not “wrong.” The trained model's semantics currently include the numerical ordering of the block solve. A serial kernel can become a new training semantics, but it is not a drop-in exact checkpoint backend.
