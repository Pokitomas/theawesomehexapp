# ARCHIE Operator-Schema Edge — 2026-08-12

## Boundary

This is a synthetic exact-arithmetic mechanism court, not a live-model speedup claim.

The current live-model admission boundary remains unchanged: the real resident tensor microscope has not yet produced an admitted scientific receipt, and any atlas built from model state still requires actual Delta carrier state/write/query/lagged-read traces.

## Result: raw support-class growth is not the right asymptotic variable

The earlier interrupt-atlas cost law used `D_T`, the number of distinct support-equivalence classes observed by event `T`:

`C_T/T = rho + (1 + kappa - rho) D_T/T`.

That law is correct for an atlas whose compilation unit is one support class. It is not a universal lower bound once the compiler can certify a family of context-indexed predictive operators.

Suppose a supported operator family satisfies

`O_a(c) = sum_j phi_j(c) G_{a,j}`

inside a declared jurisdiction, with future-law closure proving that the family is behaviorally sufficient for the supported query/action words.

Then the expensive compilation object is the law/schema basis `{G_{a,j}}`, not every concrete context `c`. Distinct support fingerprints may grow as `Theta(T)` while the predictive operator-family rank remains bounded.

The synthetic court in `archie_operator_schema_court_v0.py` constructs 10,000 distinct context-indexed supports over exact finite-field arithmetic. Each of two action families is quadratic in context and has exact flattened operator span rank 3. Three context anchors per action recover the complete family exactly; the clean full finite domain has zero matrix mismatch.

Cost fixture:

- class-keyed operator acquisitions: 20,000
- schema anchors: 6
- anchor fraction: 0.0003 = 0.03%
- support fingerprints: 10,000
- operator-family rank per action: 3

So `D_T/T -> 1` does not imply non-vanishing reference duty when support instances share a certified law.

## Replacement variable

Use law-schema growth rather than support-class growth.

Let:

- `L_T` = number of newly required predictive law/schema dimensions or generators by event `T`;
- `E_T` = schema exceptions that require a split or new residual law;
- `V_T` = source/version recertification events;
- `rho` = cheap/reference execution cost ratio.

A more useful runtime accounting target is of the form

`C_T/T = rho + A L_T/T + B E_T/T + R V_T/T + probe_T/T`

for court-defined costs `A,B,R`.

This is not yet a theorem for the live nonlinear model. It is the compiler objective suggested by the exact counterexample: make `L_T`, `E_T`, and recertification/probe burden sublinear even if concrete situations never repeat.

## Falsifier: one-step observability is insufficient

The defect fixture mutates one action-0 operator at context 7331 in a row invisible to the immediate decoder.

Consequences:

- one-step signature `C O_0(c)` is unchanged at the defective context;
- a naive immediate-observable verifier therefore misses the mutation;
- composing the next action routes the hidden coordinate into the decoder;
- the depth-2 future-law signature changes;
- the action-0 operator span rank grows from 3 to 4.

Therefore operator-schema admission must use the existing predictive/future-law closure idea, not one-step projection equality.

This agrees with the current ARCHIE rule that Jacobian-null or immediate-output-null directions are not deletable merely because they are locally invisible.

## Promotion boundary

Three samples fitting a quadratic do not prove an unbounded quadratic law.

A parametric schema may be promoted only with one of:

1. a source-bound structural certificate tying the operator family to a hashed implementation/weight-derived construction;
2. exhaustive verification over a finite declared domain;
3. a conservative approximate jurisdiction with residual/derivative bounds and transported error tubes;
4. a proof-producing generator/closure construction whose failure refuses before cheap execution.

A finite held-out sample by itself is evidence for a candidate, not a certificate.

## Live-model translation

After the real Delta temporal trace contract is satisfied, do not immediately cluster every observed state into a table entry.

For each Delta head/layer and declared intervention family:

1. build the observable predictive quotient first;
2. collect actual context-conditioned transition/write/read operators on that quotient;
3. estimate the rank of the operator family, not only state rank;
4. search for a small basis `G_j` and cheap coefficient map `phi(context)`;
5. close candidate operators under supported future action/query words;
6. attack apparently null residual directions with finite interventions;
7. attach support/source fingerprints and nonlinear error-tube jurisdiction;
8. count new operator-basis dimensions and schema exceptions over time.

The decisive measurement becomes:

`new predictive operator dimensions / causal transitions`

alongside expensive reference duty, wall time, energy, and correctness.

If operator-basis growth is sublinear while raw contexts remain novel, ARCHIE has a path to asymptotically decreasing expensive compute without requiring the world itself to repeat.
