# Archie

Archie is an experimental local-first model and execution system for turning unfinished human intentions into verified digital outcomes.

## Current empirical truth

The repository's former canonical neural lane—Qwen3-1.7B with information-budgeted causal-fork RSLoRA—has been retired from the current default branch. Its trainer, fuser, profile, workflow, and method note are no longer present. Historical bounded CPU receipts remain preserved under `00-ARCHIE-MODEL/evidence/`.

The repository therefore does **not** currently name a canonical neural architecture from package prose alone. The next identity must be reconstructed from the live trainer source, its direct dependency graph, exact configuration, and run receipts.

```text
promotion: not-admitted
admitted checkpoint: none established in repository
historical RSLoRA evidence: preserved, noncanonical
current neural identity: resolve from live executable source + receipts
```

Start with `00-ARCHIE-MODEL/STATUS.json`, then `MODEL.json`, `BENCHMARKS.json`, and the evidence directory.

## What remains invariant

Archie should be judged by verified outcomes rather than persuasive prose: exact artifact identity, clean evaluation, no false completion claims, no unauthorized effects, reproducibility, bounded resource use, and retention after deployment transformations. `00-ARCHIE-MODEL/BENCHMARKS.json` records those gates.

## Repository interpretation rule

Treat model training code, executable courts/specimens, product/runtime infrastructure, transport, UI, and historical experiments as different categories. A component belongs to the neural model only when the current trainer dependency graph actually imports and executes it. File count and naming do not establish architecture.

Historical evidence should be retained even when its implementation lane is deleted; stale claims that historical code is current should not.
